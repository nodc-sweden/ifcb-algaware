# Format one microscopy station for an LLM prompt

Format one microscopy station for an LLM prompt

## Usage

``` r
format_microscopy_station_for_prompt(obs, chl_measure = "fluorescence")
```

## Arguments

- obs:

  Enriched microscopy observations for one station visit.

- chl_measure:

  Chlorophyll measurement terminology key.

## Value

Character string.
