# Format the microscopy stations for the cruise summary prompt

Format the microscopy stations for the cruise summary prompt

## Usage

``` r
format_microscopy_summary_block(microscopy, chl_measure = "fluorescence")
```

## Arguments

- microscopy:

  Enriched microscopy observations, or NULL.

- chl_measure:

  Chlorophyll measurement terminology key.

## Value

Character string (empty without microscopy data).
