# List H5 classification files, optionally restricted to given samples

List H5 classification files, optionally restricted to given samples

## Usage

``` r
list_h5_files(h5_dir, sample_ids = NULL)
```

## Arguments

- h5_dir:

  Directory containing .h5 files (searched recursively).

- sample_ids:

  Optional character vector of sample PIDs to keep.

## Value

Character vector of full file paths.
