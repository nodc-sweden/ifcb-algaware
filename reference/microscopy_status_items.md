# Status lines for loaded microscopy samples

Status lines for loaded microscopy samples

## Usage

``` r
microscopy_status_items(status)
```

## Arguments

- status:

  The `status` table from
  [`select_gap_samples()`](https://nodc-sweden.github.io/ifcb-algaware/reference/select_gap_samples.md).

## Value

List of items with `ok` (logical) and `label`.
