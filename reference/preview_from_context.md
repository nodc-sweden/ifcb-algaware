# Preview one threshold value from a prepared context

Preview one threshold value from a prepared context

## Usage

``` r
preview_from_context(context, value)
```

## Arguments

- context:

  A list from
  [`preview_context()`](https://nodc-sweden.github.io/ifcb-algaware/reference/preview_context.md).

- value:

  Proposed threshold.

## Value

A list as returned by
[`preview_threshold()`](https://nodc-sweden.github.io/ifcb-algaware/reference/preview_threshold.md).
